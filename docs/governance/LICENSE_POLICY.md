# Política de Licenciamiento de ARV

La protección de ARV depende de una separación arquitectónica rigurosa, no de una única licencia. Cualquier persona puede verificar una prueba local; solamente ARV puede emitir y administrar una prueba oficial con valor comercial.

* **Esquemas y Vectores (arv-spec):** Se utilizará Apache-2.0. Queda estrictamente prohibido el uso de licencias Creative Commons (como CC BY-ND 4.0) para código, esquemas JSON/YAML o herramientas ejecutables.
* **Kernel Local (arv-proof):** Provisionalmente MPL-2.0. Aplica copyleft a nivel de archivo para asegurar que las modificaciones al motor criptográfico regresen al proyecto. Componentes que requieran protección anti-SaaS se aislarán en repositorios separados bajo licencias de Source Available.
* **SDKs (arv-sdk):** Se utilizará Apache-2.0 para garantizar máxima interoperabilidad empresarial.
* **Superficie Comercial:** Todos los servicios administrados, APIs y portales operan bajo esquema Propietario (Todos los derechos reservados).

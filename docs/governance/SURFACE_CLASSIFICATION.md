# Clasificación de Superficies de ARV

Esta matriz define la frontera estricta entre el código abierto, el código disponible y la propiedad intelectual cerrada de ARV.

| Repositorio o Componente | Superficie | Licencia o Régimen |
| :--- | :--- | :--- |
| `arv-spec` (schemas y test vectors) | Pública OSS | Apache-2.0 |
| `arv-proof` (kernel mínimo LOCAL_L0) | Pública OSS | MPL-2.0 provisional |
| `arv-sdk` (integración básica) | Pública OSS | Apache-2.0 |
| Visor offline mínimo | Pendiente delimitación | OSS o Source Available |
| `arvseal-web` (comercial) | Cerrada por ahora | Propietaria |
| ARV Snap official issuance | Administrada | Propietaria |
| Baúl de pruebas | Secreta | Propietaria |
| ProofOps | Privada / Administrada | Propietaria |
| Evidence Certificate | Privada / Administrada | Propietaria |
| Bundle Evidence Package | Privada / Administrada | Propietaria |
| Dispute Pack | Privada / Administrada | Propietaria |
| Policy Engine y Dispute Logic | Privada | Propietaria |
| API empresarial y Gateway | Administrada | Propietaria |
| Adaptadores externos (KMS, PostgreSQL, etc.) | Privada hasta clasificación | Propietaria inicialmente |
| Claves de firmado y secretos productivos | Secreta | Nunca publicar |
